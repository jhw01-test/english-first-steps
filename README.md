# 영어 첫걸음

일정·단어 학습·기초 영어·상황별 회화·전공 영어·토익·토스·오픽을 한곳에서 관리하는 학습 웹앱입니다.

## 사용 방법

- 수업마다 소리 → 단어 → 문장 → 5문항 퀴즈 순서로 학습하고 활용 탭에서 문장 조립과 상황 대화를 연습합니다.
- 발음 듣기는 버튼을 눌러 실행하며 기기에 설치된 영어 음성을 사용합니다.
- 진도·퀴즈 점수·즐겨찾기·설정은 현재 브라우저에 저장합니다.
- 설정의 **학습 기록 백업 / 백업 불러오기**로 기기 간 기록을 옮길 수 있습니다.
- Safari와 홈 화면 앱의 저장 공간은 다를 수 있으므로 홈 화면 앱에서 처음부터 학습하거나 백업 파일을 불러오세요.

## 학습 플래너와 전체 과정

새 계획 기본값은 평일 30분·주말(토·일) 각 60분, 토스·오픽 말하기 중심과 자동 이월입니다. 기존 계획의 선택 요일은 유지하며 학습 일정 → 주말 확장·자동 이월 적용으로 토·일을 한 번에 추가할 수 있습니다.

- **오늘 학습 / 학습 일정**: 시작일, 주간 공부 요일, 하루 30·60·90분, 균형·토익 중심·말하기 중심 학습을 선택하면 날짜별로 단어·기초·회화·전공·시험 학습을 배정합니다. 날짜 이동, 개인 일정 추가·완료·삭제, 월간 달력과 미완료 일정 목록을 제공합니다. 예상 시간이며 실제 공부 시간을 측정하거나 알림을 보내지는 않습니다.
- **단어 학습실**: 기본 641개 단어·표현(전력·전기·에너지 분야 선택 기준), 오늘의 단어, 시험별 단어, 즐겨찾기, 오답, 복습 대상, 직접 추가한 단어를 선택합니다. 카드 뒤집기·발음 듣기·자기 점검과 뜻 고르기·영어 고르기·듣기·직접 입력·혼합 퀴즈를 지원합니다. 5·10·20문제를 선택하며 단어 수가 적으면 가능한 만큼 출제합니다. 직접 추가한 단어는 1,000개까지 수정·삭제할 수 있습니다.
- **단어 복습**: 틀린 단어는 오늘, 기억한 단어는 1·3·7·14·30일 간격으로 복습합니다. 오늘의 단어에는 복습 대상이 최대 절반 포함됩니다. 같은 날 반복해서 맞히면 숙련 단계가 계속 오르지 않으며, 예정일보다 일찍 복습해도 기존 복습일이 뒤로 밀리지 않습니다.
- **기초 과정**: 기존 72회 수업, 문장 조립, 상황 대화, 빈칸 퀴즈와 오답 복습을 유지합니다. 12개 단계의 교육 내용을 실제 일정에 배분하므로 주간 학습일 수와 선택 시간에 따라 전체 기간은 달라집니다.
- **시험 과정**: 토익 8챕터·24연습, 토스 6챕터·18연습, 오픽 8챕터·24연습으로 총 22챕터·66활동입니다. 챕터마다 핵심 개념, 필수 단어, 단어 퀴즈와 연습을 제공합니다. 기존 18개 활동의 ID와 학습 기록을 유지하며 48개 활동을 추가했습니다.
- **리포트**: 기초·시험 진도, 완료 챕터, 최근 단어 퀴즈 정확도, 복습 대상을 표시합니다. 말하기는 질문·예시 듣기, 연습 타이머, 답변 메모와 자기 점검 방식입니다. 직접 만든 기초·입문 과정으로 공식 기출·모의고사나 시험 점수·등급 채점이 아닙니다.

일정과 단어·퀴즈 기록은 기존 계정별 JSON 기록에 함께 저장하므로 새로운 SQL 작업은 필요 없습니다. 기존 Google 로그인과 데이터베이스의 사용자별 행 보안(RLS)을 사용합니다. 비로그인은 기기에 저장하며, 로그인 전 기기 기록을 가져오면 계정 기록을 대체하므로 기존 기록을 먼저 백업할 수 있습니다. 계획을 바꿔도 학습 기록은 유지하고, 직접 날짜를 옮긴 일정은 이동한 날짜를 유지합니다.

## 주말·이월, 연속 카드와 자료실

- 평일과 주말의 시간 예산을 별도로 설정합니다. 30분은 일반 학습 1개·시험 학습 1개·단어, 60분은 일반 학습 2개·시험 학습 2개·단어, 90분은 일반 학습 3개·시험 학습 4개·단어를 배정합니다. 일반 학습은 기초·회화·전공을 번갈아 배정하며, 시험 학습에는 토스·오픽 답변 틀이 포함됩니다. 하루 배정은 예상 시간입니다.
- 자동 이월은 미완료 학습을 현재 또는 다음 선택 학습일부터 시간 예산 안에 배정하고 이후 학습을 뒤로 나눕니다. 완료 항목은 실제 완료일에 남아 그날의 시간 예산을 차지하므로, 하나 끝낼 때마다 새 과제가 무한히 끼어들지 않습니다. 직접 추가한 일정과 직접 고정한 미래 날짜는 유지합니다. 자동 이월을 끄면 원래 날짜에서 직접 관리합니다.
- 플래시카드의 ‘기억나요’는 복습일까지 카드에서 제외합니다. 어려운 단어는 뒤로 보내고 새 카드와 섞어 재출제합니다. 대기열과 위치는 사용자별로 저장되며 새로고침해도 이어집니다. 카드를 모두 기억하면 완료 화면을 표시합니다. ‘오늘의 단어’ 카드에서는 일일 퀴즈 분량을 넘어 전체 단어가 이어집니다.
- 기본·토익·토스·오픽·회화·전공 단어장을 분리하고 공통 단어의 학습 상태는 공유합니다. 직접 추가한 단어에도 분류를 지정할 수 있습니다. 전력·전기·에너지 분야 선택 기준으로 단어·표현은 중복을 합쳐 641개입니다. 같은 단어도 묶음에 맞는 뜻을 표시합니다.
- 사진 연습에는 Wikimedia Commons에서 CC0로 제공되는 실제 사진 두 장을 사용합니다. 크레딧은 사진 아래와 `assets/README.txt`에 표시합니다.
- 공식 자료실은 ETS 샘플 PDF, 한국TOEIC위원회 실제 기출 영상, ACTFL OPIc 안내 PDF와 공식 사이트로 연결합니다. PDF·영상 원문은 저장소에 복제하지 않습니다.
- 자체 모의연습은 토익 사진 포함 12문항/12분, 토스 유형 11문항/20분, 오픽 주제 12문항/40분입니다. 시간 만료 시 제출하고 토익 정답·해설, 말하기 메모·예시를 표시합니다. 공식 점수·등급 환산이나 음성 채점은 하지 않습니다. 최근 제출 결과 5회가 계정 기록에 저장됩니다. 제출 전에는 화면 이동 시 진행 중인 답변을 버릴지 확인합니다.

## 상황별 회화·전공 영어·말하기 답변 틀

**회화·전공** 메뉴에서 새로 작성한 30챕터를 학습합니다. 각 챕터의 단어는 분류된 단어장과 연결되고, 완료 여부·답변 메모·자기 점검·편집한 빈칸은 백업 및 계정 동기화에 포함됩니다.

- **상황별 기초 회화 10챕터**: 인사, 카페, 식당, 쇼핑, 길 안내, 교통, 호텔, 약속, 전화·다시 묻기, 약국. 단어·표현 60개, 패턴 30개, 대화 60턴, 상황 응답 퀴즈와 역할극을 제공합니다.
- **전력·전기·에너지 6챕터**: 전압·전류·전력·에너지, 전력망, 재생에너지 계통 연계, 에너지저장장치와 SOC, 주파수·전압 제어, 계통 모델·최적화. 공통 연구·발표 3챕터(논문, 실험·데이터, 발표·질의응답)를 함께 제공합니다. 총 54개 단어·표현과 27개 문장 패턴을 학습합니다. 전공 선택을 연구·발표 공통으로 바꾸어도 기존 기록은 유지합니다.
- **토스 답변 틀 5챕터**: 사진 묘사, 일상 응답, 정보표 응답, 선호 선택, 의견 확장.
- **오픽 답변 틀 6챕터**: 묘사, 일상, 과거 경험, 비교, 질문 역할극, 문제 해결.

답변 틀은 빈칸을 내 경험에 맞게 편집하고 완성된 문장을 듣는 방식입니다. 예시와 다른 연습 질문을 제공해 질문에 맞는 답변을 연습합니다. 템플릿의 단어·표현 55개는 해당 시험 단어장에 포함됩니다. 발음 듣기는 기기 TTS이며 음성 채점이나 공식 점수·등급 환산은 제공하지 않습니다.

공식 형식과 응시자 안내를 참고하고 학습 문장·대화·답변은 새로 작성했습니다. [ETS Speaking/Writing 샘플 PDF](https://www.ets.org/content/dam/ets-org/pdfs/toeic/toeic-speaking-writing-sample-tests.pdf), [IIBC Speaking 유형 안내](https://www.iibc-global.org/english/toeic/test/speaking/about/format.html), [ACTFL OPI/OPIc 응시자 안내](https://www.actfl.org/assessments/postsecondary-assessments/opi/tips-for-opi-and-opic-test-takers)로 연결하며 교재 원문을 복제하지 않습니다.

회화·전공은 계획 설정에서 포함 여부를 바꿀 수 있습니다. 기본값은 두 과정 모두 포함이며, 평일 30분·토일 각 60분의 시간을 유지하고 전체 학습 기간을 조절합니다. 리포트에 회화·전공·답변 틀 완료 수를 각각 표시합니다.

사용자의 로컬 토익 교재 파일은 아직 전달되지 않았습니다. 현재 토익 과정은 자체 입문 과정이며, 실제 교재 목차와 단어에 맞춘 편성에는 교재 목차·단어 PDF 또는 영어 자료 ZIP이 필요합니다.

## Google 로그인 연결 설정

앱에는 Google 로그인과 개인별 기록 동기화를 구현했습니다. Supabase의 Google 제공자 설정이 꺼져 있으면 로그인 버튼은 비활성화되고 기기 저장으로 학습할 수 있습니다. 이메일 인증번호·SMTP 설정은 사용하지 않습니다.

1. Supabase SQL Editor에서 `SUPABASE_SETUP.sql`을 실행합니다. 사용자별 행 보안(RLS)과 동시 수정 감지용 저장 함수를 만듭니다. 같은 SQL을 다시 실행할 수 있습니다.
2. Google Cloud의 Google Auth Platform에서 OAuth 앱을 설정합니다. Audience는 개인 Google 계정 사용자가 로그인할 수 있도록 External을 선택합니다. 기본 로그인 범위 `openid`, `email`, `profile`만 사용합니다. Testing 상태에서는 로그인할 계정을 Test users에 등록합니다. 다른 사용자가 사용할 준비가 되면 Audience의 게시 상태를 Production으로 전환해야 합니다.
3. Clients → Create client에서 Web application을 선택합니다. Authorized JavaScript origins는 `https://jhw01-test.github.io`, Authorized redirect URIs는 `https://aicaaawuortmdqslkgbp.supabase.co/auth/v1/callback`입니다.
4. Google이 발급한 Client ID와 Client secret은 Supabase Authentication → Sign In / Providers → Google에 직접 입력하고 활성화합니다. Client secret은 채팅·프런트엔드·GitHub 저장소에 넣지 않습니다.
5. Supabase Authentication → URL Configuration에서 Site URL을 `https://jhw01-test.github.io/english-first-steps/`로 설정합니다. Redirect URLs에는 `https://jhw01-test.github.io/english-first-steps/`와 `https://jhw01-test.github.io/english-first-steps/index.html` 두 주소를 허용합니다.
6. 앱 → 내 계정 → 연결 상태 다시 확인 → Google로 로그인을 실행합니다. 실제 계정 로그인과 두 기기 기록 동기화는 제공자 설정 후 확인해야 합니다.

로그인은 같은 브라우저에서 돌아오는 PKCE 코드 교환 방식을 사용합니다. 인증 코드는 URL에서 제거하며, 코드와 검증값을 함께 확인한 뒤 계정 기록을 불러옵니다. 로그아웃하면 이 기기의 계정 캐시와 세션이 삭제되고 로그인 전 기기 기록으로 돌아갑니다.

계정 기록과 비로그인 기록은 별도 저장됩니다. 기기 기록 가져오기는 사용자가 확인한 뒤 실행됩니다. 오프라인 변경은 기기에 남고, 온라인 기록의 버전이 다르면 사용자가 사용할 기록을 선택합니다. 덮어쓰기 전 백업을 내보낼 수 있습니다. 공용 기기에서는 사용 후 로그아웃하세요.

## GitHub Pages 설정

저장소 Settings → Pages → Build and deployment에서 **Deploy from a branch**, **main**, **/ (root)**를 선택하고 Save를 누릅니다. GitHub가 배포 완료를 표시한 실제 주소를 사용하세요.

`index.html`에는 CSS·수업 데이터·앱 코드가 포함되어 있습니다. `app.js`, `style.css`, `curriculum.json`은 편집용 사본입니다. 편집 시 HTML에 포함된 내용도 함께 갱신해야 합니다.

## 점검 범위
