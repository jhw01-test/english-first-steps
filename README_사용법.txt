하루 영어 첫걸음 v1 — 12주 영어 기초 학습 프로그램
================================================

이 프로그램에는 12주 × 주 6회 = 총 72회의 학습과 매 수업 5개 단어,
알파벳 읽기, 파닉스 규칙, 짧은 문장, 5문제 퀴즈가 담겨 있습니다.

1. 컴퓨터에서 이용하기 (가장 간단)
   - ZIP 압축을 푼 다음 index.html 파일을 Chrome, Edge, Safari 등에서 엽니다.
   - 또는 함께 제공된 단일 HTML 파일(영어_첫걸음_12주_학습프로그램.html)을 엽니다.
   - 음성 재생은 브라우저/기기의 영어 음성합성 기능을 사용합니다.

2. 아이폰·아이패드에서 이용하기 (권장)
   - ZIP에 포함된 파일들을 GitHub Pages 또는 다른 정적 웹 호스팅 서비스(HTTPS)에 업로드합니다.
   - Safari로 배포 주소에 접속하여 [공유] > [홈 화면에 추가]를 사용합니다.
   - iOS 파일 앱의 HTML 미리보기에서는 자바스크립트, 음성, 저장 기능이 제한될 수 있습니다.
   - 웹 호스팅 없이도 단일 HTML을 여는 방법이 있지만, 진도 저장이 안정적이지 않을 수 있습니다.

3. 학습 방법
   - [오늘 학습]에서 현재 수업을 시작합니다.
   - [1 · 소리]에서 알파벳/발음 규칙을 익히고,
   - [2 · 단어]에서 오늘의 5단어를 듣고 따라 읽습니다.
   - [3 · 문장]을 읽은 뒤 [4 · 퀴즈] 5문제를 풀고 [오늘 학습 완료]를 누릅니다.
   - 다음 날 복습할 단어가 첫 화면에 나타납니다.

4. 주의사항
   - 진도는 해당 브라우저의 로컬 저장소(localStorage)에 저장됩니다.
   - 다른 기기와 자동 동기화되지 않습니다.
   - 설정에서 백업(JSON)과 백업 불러오기를 이용해 학습 기록을 보존하세요.
   - 마이크 녹음/발음 채점, 자동 알림, 클라우드 계정 동기화 기능은 아직 없습니다.
   - 인터넷 없이 HTML 자체는 동작하지만, 발음 음성은 기기의 영어 음성 설치 상태에 따라 재생되지 않을 수 있습니다.
   - 일별 학습 내용은 기본 영어 학습용 예시이며, 특정 시험 대비 교재가 아닙니다.

5. 맞춤 확장 방향
   - 나중에 보유한 토익/토익스피킹/오픽 교재의 목차를 바탕으로 문제 유형별 과정을 추가할 수 있습니다.
   - 저작권 문제를 피하기 위해 교재 내용은 임의로 복제하지 않습니다.
